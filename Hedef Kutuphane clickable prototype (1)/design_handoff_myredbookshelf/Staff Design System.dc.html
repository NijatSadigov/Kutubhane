Staff design system

For librarians, teachers and school admins. Same brand as the reader app, but in a deep-blue shell with denser type, tables and role colours, so staff always know they’re in admin mode.

LibrarianTeacherSchool admin
1 · Always in admin modeDeep-blue sidebar, a role chip in the top bar and a white work area. Never confused with the student app.
2 · Dense but calm13px base text, 44px table rows and 12px card radius. The serif is only used for book titles and big headlines.
3 · Status is colour + wordsEvery state is a pill with a label, never colour alone. Coral is only for problems.
4 · Minors firstStaff see full names inside their school. Anything shared outside it is masked (A*** M***) or locked.
